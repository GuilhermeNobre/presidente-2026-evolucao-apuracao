Módulo 02 · A apuração em movimento

Uma reta para cada candidato

Cada ponto é uma atualização do TSE: no eixo x, o % de urnas apuradas; no y, o % dos votos válidos. A linha tracejada é a regressão linear simples ŷ = β₀ + β₁·x, e o seu valor em x = 100 é a "previsão" de fim de apuração. Mude o treino para ver o que a reta teria previsto no meio da noite.
